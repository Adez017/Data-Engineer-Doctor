# Docs review rubric

## Summary

Use this rubric to keep docs correct, complete, discoverable, and minimal.

## Rubric

| Dimension | Check |
| --- | --- |
| Correctness | Commands and flags are valid and tested |
| Completeness | Top user queries are covered with exact answer locations |
| Discoverability | Pages contain searchable terms users actually type |
| Minimalism | No unnecessary repetition; summary-first structure |
| Consistency | Terminology uses deterministic/investigation/AI explanation modes |
| Navigation | Clear next steps and See also links |

## Expected output

Every documentation change can be reviewed against one shared standard.
