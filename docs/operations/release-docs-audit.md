# Release docs audit checklist

## Summary

Recurring release-time audit to keep docs aligned with behavior.

## Checklist

- [ ] Rebuild docs in strict mode
- [ ] Validate all command flags/options against CLI help
- [ ] Validate troubleshooting entries against recent issues/incidents
- [ ] Update FAQ with newly repeated user questions
- [ ] Validate diagnosis counts/categories against current catalog
- [ ] Confirm AI provider/environment variable guidance is current
- [ ] Confirm privacy/security statements still match implementation
- [ ] Confirm internal links and anchors resolve

## Expected output

A release where docs and product behavior remain synchronized.
