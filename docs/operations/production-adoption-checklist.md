# Production adoption checklist

## Summary

Checklist for adopting DEDoc safely in team workflows and CI.

## Checklist

- [ ] Pin Python runtime to 3.11/3.12
- [ ] Verify deterministic mode workflow on representative failures
- [ ] Define owner for diagnosis catalog updates
- [ ] Integrate JSON output into incident workflow/alerting
- [ ] Define privacy policy for optional AI explanation mode
- [ ] Add DEDoc runbook links in team on-call docs
- [ ] Baseline common failures with recipe examples
- [ ] Add periodic docs and catalog audits per release

## Expected output

A repeatable, auditable diagnosis workflow used by engineers and CI.
