# Docs success metrics

## Summary

Track whether docs are actually answering user questions.

## Metrics to track

- Search no-result terms (top unknown queries)
- Top exit pages (where users stop unexpectedly)
- Most-viewed troubleshooting topics
- FAQ additions per release cycle
- Time-to-answer for common support questions

## Review cadence

- Review metrics every release
- Feed top misses into FAQ, troubleshooting, and recipes
- Update Top 25 user query map when recurring gaps appear
